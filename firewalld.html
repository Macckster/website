firewalld

Quick reference. Press / to filter.

Basics

Status & service control

sudo firewall-cmd --state
sudo systemctl status firewalld
sudo systemctl enable --now firewalld

Make runtime changes permanent

Without --permanent, changes are lost on reload/reboot. Either test live then save, or write permanent then reload.

sudo firewall-cmd --runtime-to-permanent
# or
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload

Temporary rule (auto-expires)

sudo firewall-cmd --add-port=8080/tcp --timeout=10m

Inspect

Everything in the active zones

sudo firewall-cmd --get-active-zones
sudo firewall-cmd --list-all
sudo firewall-cmd --list-all-zones

One zone

sudo firewall-cmd --zone=public --list-all

Just services / ports

sudo firewall-cmd --list-services
sudo firewall-cmd --list-ports

Available predefined services

sudo firewall-cmd --get-services
sudo firewall-cmd --info-service=ssh

Zones

Default zone

sudo firewall-cmd --get-default-zone
sudo firewall-cmd --set-default-zone=home

Which zone is an interface in?

sudo firewall-cmd --get-zone-of-interface=eth0

Move interface to a zone

sudo firewall-cmd --permanent --zone=internal --change-interface=eth1
sudo firewall-cmd --reload

Bind a source network to a zone

Traffic from this subnet uses the zone's rules regardless of interface. Check what a range covers with /cidr.

sudo firewall-cmd --permanent --zone=trusted --add-source=192.168.1.0/24
sudo firewall-cmd --reload

Create a new zone

sudo firewall-cmd --permanent --new-zone=lab
sudo firewall-cmd --reload

Services & ports

Open a service

sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload

Close a service

sudo firewall-cmd --permanent --remove-service=cockpit
sudo firewall-cmd --reload

Open a port / range

sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --permanent --add-port=60000-61000/udp
sudo firewall-cmd --reload

Close a port

sudo firewall-cmd --permanent --remove-port=8080/tcp
sudo firewall-cmd --reload

Check if something is open

sudo firewall-cmd --query-service=ssh
sudo firewall-cmd --query-port=8080/tcp

Custom service definition

sudo firewall-cmd --permanent --new-service=myapp
sudo firewall-cmd --permanent --service=myapp --add-port=9000/tcp
sudo firewall-cmd --permanent --service=myapp --set-description="My app"
sudo firewall-cmd --reload
sudo firewall-cmd --permanent --add-service=myapp

Rich rules

Allow a port from one IP only

sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="10.0.0.5" port port="5432" protocol="tcp" accept'
sudo firewall-cmd --reload

Allow SSH from a subnet

Not sure what a /24 covers? /cidr

sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" service name="ssh" accept'
sudo firewall-cmd --reload

Block an IP

sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="203.0.113.7" drop'
sudo firewall-cmd --reload

Rate-limit + log

sudo firewall-cmd --permanent --add-rich-rule='rule service name="ssh" log prefix="ssh: " level="info" limit value="3/m" accept'
sudo firewall-cmd --reload

List / remove rich rules

Remove with the exact same string you added.

sudo firewall-cmd --list-rich-rules
sudo firewall-cmd --permanent --remove-rich-rule='rule family="ipv4" source address="203.0.113.7" drop'

NAT & forwarding

Forward a local port

sudo firewall-cmd --permanent --add-forward-port=port=80:proto=tcp:toport=8080
sudo firewall-cmd --reload

Forward to another host

Needs masquerade on the zone.

sudo firewall-cmd --permanent --add-masquerade
sudo firewall-cmd --permanent --add-forward-port=port=2222:proto=tcp:toport=22:toaddr=192.168.1.50
sudo firewall-cmd --reload

Masquerade (NAT / router)

sudo firewall-cmd --permanent --zone=external --add-masquerade
sudo firewall-cmd --query-masquerade
sudo firewall-cmd --reload

IP sets

Blocklist via ipset

sudo firewall-cmd --permanent --new-ipset=blocklist --type=hash:net
sudo firewall-cmd --permanent --ipset=blocklist --add-entry=198.51.100.0/24
sudo firewall-cmd --permanent --zone=drop --add-source=ipset:blocklist
sudo firewall-cmd --reload

Load entries from a file

sudo firewall-cmd --permanent --ipset=blocklist --add-entries-from-file=bad-ips.txt
sudo firewall-cmd --reload

Emergency & debugging

Panic mode (drop ALL traffic)

This will kill your SSH session if you're remote.

sudo firewall-cmd --panic-on
sudo firewall-cmd --panic-off
sudo firewall-cmd --query-panic

Log denied packets

sudo firewall-cmd --set-log-denied=all
sudo journalctl -kf | grep -i reject

Reload vs complete reload

--complete-reload also drops connection state.

sudo firewall-cmd --reload
sudo firewall-cmd --complete-reload

Validate config / where it lives

sudo firewall-cmd --check-config
ls /etc/firewalld/zones/
ls /usr/lib/firewalld/services/

See the generated nftables ruleset

sudo nft list ruleset
