git

Quick reference. Press / to filter.

Setup

Identity & defaults

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global pull.rebase true
git config --global push.autoSetupRemote true

Handy aliases

git config --global alias.st "status -sb"
git config --global alias.lg "log --oneline --graph --decorate --all"
git config --global alias.amend "commit --amend --no-edit"

Where is a setting coming from?

git config --list --show-origin

Everyday

Stage & commit

git add -p
git commit -m "message"
git commit -am "message"

What changed?

git status -sb
git diff
git diff --staged
git diff main...HEAD

History

git log --oneline --graph --decorate
git log -p -- path/to/file
git log -S "someFunction"
git log --author="Your Name" --since="2 weeks ago"

Who wrote this line?

git blame -L 40,60 script.js
git show <commit>

Branches

Create / switch

git switch -c feature/thing
git switch main
git switch -

List

git branch -vv
git branch -a
git branch --merged main

Rename / delete

git branch -m new-name
git branch -d feature/thing
git branch -D feature/thing
git push origin --delete feature/thing

Clean up branches gone from the remote

git fetch --prune
git branch -vv | awk '/: gone]/{print $1}' | xargs -r git branch -D

Remotes

Manage remotes

git remote -v
git remote add origin git@github.com:user/repo.git
git remote set-url origin git@github.com:user/repo.git

Sync

git fetch --all --prune
git pull --rebase
git push -u origin HEAD

Safe force push

Refuses to push if someone else pushed in the meantime.

git push --force-with-lease

Undo

Discard changes to a file

git restore path/to/file
git restore --staged path/to/file

Fix the last commit

git commit --amend
git commit --amend --no-edit

Undo last commit, keep changes

git reset --soft HEAD~1   # keep staged
git reset HEAD~1          # keep unstaged

Throw away local commits and changes

Destructive. Uncommitted work is gone for good.

git reset --hard origin/main

Undo a pushed commit

git revert <commit>

Recover "lost" commits

git reflog
git switch -c rescue HEAD@{3}

Remove untracked files

git clean -nd   # dry run
git clean -fd

Stash

Stash work in progress

git stash push -m "wip"
git stash push -u -m "wip incl. untracked"
git stash list

Get it back

git stash pop
git stash apply stash@{1}
git stash show -p stash@{0}
git stash drop stash@{0}

Rebase & merge

Rebase on latest main

git fetch
git rebase origin/main

Squash / reorder commits

git rebase -i HEAD~5
git rebase -i --autosquash origin/main

Fixup commit for later autosquash

git commit --fixup=<commit>
git rebase -i --autosquash origin/main

Conflicts

git status
git add path/to/resolved
git rebase --continue
git rebase --abort
git merge --abort

Take one side of a conflict

During a rebase, "ours" and "theirs" are swapped.

git checkout --ours path/to/file
git checkout --theirs path/to/file

Cherry-pick

git cherry-pick <commit>
git cherry-pick A^..B

Tags

Create & push

git tag -a v1.2.0 -m "v1.2.0"
git push origin v1.2.0
git push --tags

Delete

git tag -d v1.2.0
git push origin --delete v1.2.0

Power tools

Find the commit that broke it

git bisect start
git bisect bad
git bisect good v1.0.0
# test, then mark each step: git bisect good / bad
git bisect reset

Automated bisect

git bisect start HEAD v1.0.0
git bisect run ./test.sh

Second working copy of another branch

git worktree add ../repo-hotfix hotfix
git worktree list
git worktree remove ../repo-hotfix

Search tracked files

git grep -n "TODO"

Stop tracking a file but keep it on disk

git rm --cached .env
echo ".env" >> .gitignore

Shallow clone

git clone --depth 1 git@github.com:user/repo.git
